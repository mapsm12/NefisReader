安装

安装软件包并读取模型输出

需要 Linux x86-64 和 Python 3.9+。安装依赖时需要联网。 下载软件包 后，在下载目录中运行以下命令。无需安装 Delft3D。

Terminal · Linux
tar -xzf NefisReader-main.tar.gz
cd NefisReader-main
python3 -m venv .venv
source .venv/bin/activate
bash scripts/install.sh
d3dnefis examples/data
python examples/leer_mallas.py \
  examples/data/NETCDF_EXPORT/wavm-demo-2d.nc \
  examples/data/NETCDF_EXPORT/trim-demo-3d.nc

已有输出文件？

将 .dat 文件或运行目录传给 d3dnefis。使用 --inventory 可查看变量而不进行转换。

通过 MCP 连接智能体

本地服务器可列出变量，并读取授权目录中 NEFIS 或 NetCDF 文件的切片。需要 Python 3.10+。
