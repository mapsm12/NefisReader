INSTALAÇÃO

Instale o pacote e leia os resultados do seu modelo.

Linux x86-64, Python 3.9 ou posterior e acesso à internet para instalar as dependências. Baixe o pacote e execute estes comandos na pasta de downloads. Não é necessário instalar o Delft3D.

Terminal · Linux
tar -xzf NefisReader-main.tar.gz
cd NefisReader-main
python3 -m venv .venv
source .venv/bin/activate
bash scripts/install.sh
d3dnefis examples/data
python examples/leer_mallas.py \
  examples/data/NETCDF_EXPORT/wavm-demo-2d.nc \
  examples/data/NETCDF_EXPORT/trim-demo-3d.nc

Já tem um arquivo?

Passe um arquivo .dat ou a pasta da simulação para d3dnefis. Use --inventory para listar as variáveis sem converter.

Conecte seu agente via MCP

O servidor local lista variáveis e lê cortes de arquivos NEFIS ou NetCDF na pasta autorizada. Requer Python 3.10 ou posterior.

CRÉDITOS E ESCOPO

Software de código aberto.

NefisReader é um projeto independente. Não é um produto oficial nem tem o endosso da Deltares.

A biblioteca NEFIS é desenvolvida pela Deltares. O código-fonte, os avisos e as instruções de compilação são distribuídos separadamente no repositório. Os exemplos são sintéticos e não contêm dados de pesquisa.

O código do projeto usa a licença MIT. A biblioteca NEFIS da Deltares mantém seus próprios avisos e sua própria licença.
