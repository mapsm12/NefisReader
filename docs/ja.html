インストール

パッケージをインストールしてモデル出力を読む

Linux x86-64、Python 3.9 以降、依存関係のインストール用のインターネット接続が必要です。 パッケージをダウンロード し、ダウンロードフォルダーで以下のコマンドを実行してください。Delft3D のインストールは不要です。

Terminal · Linux
tar -xzf NefisReader-main.tar.gz
cd NefisReader-main
python3 -m venv .venv
source .venv/bin/activate
bash scripts/install.sh
d3dnefis examples/data
python examples/leer_mallas.py \
  examples/data/NETCDF_EXPORT/wavm-demo-2d.nc \
  examples/data/NETCDF_EXPORT/trim-demo-3d.nc

出力ファイルをお持ちですか？

d3dnefis に .dat ファイルまたは計算結果のフォルダーを渡します。--inventory を指定すると、変換せずに変数を確認できます。

MCP でエージェントを接続

ローカルサーバーは、許可したフォルダー内の NEFIS や NetCDF ファイルから、変数一覧や部分データを読み取ります。Python 3.10 以降が必要です。
