NefisReader

Lees NEFIS-uitvoer van Delft3D 4 en zet die om naar NetCDF. Inclusief het commando d3dnefis, een Python-API en een optionele MCP-server.

VOORBEELDEN VAN NABEWERKING

Van NetCDF naar kaarten.

NefisReader exporteert de velden. Een Python-script combineert ze tot kaarten. Beide voorbeelden gebruiken dezelfde synthetische baai, geen simulatie of gegevens uit Callao. De labels in de figuren zijn Engels.

Reproduceer beide kaarten met Python

INSTALLATIE

Installeer het pakket en lees je modeluitvoer.

Linux x86-64, Python 3.9 of hoger en internettoegang om de afhankelijkheden te installeren. Download het pakket en voer deze commando’s uit vanuit je downloadmap. Je hoeft Delft3D niet te installeren.

Terminal · Linux
tar -xzf NefisReader-main.tar.gz
cd NefisReader-main
python3 -m venv .venv
source .venv/bin/activate
bash scripts/install.sh
d3dnefis examples/data
python examples/leer_mallas.py \
  examples/data/NETCDF_EXPORT/wavm-demo-2d.nc \
  examples/data/NETCDF_EXPORT/trim-demo-3d.nc

Heb je al een uitvoerbestand?

Geef een .dat-bestand of de uitvoermap aan d3dnefis. Gebruik --inventory om variabelen te bekijken zonder ze te converteren.

Verbind je agent via MCP

De lokale server toont variabelen en leest deelgegevens uit NEFIS- of NetCDF-bestanden in de toegestane map. Vereist Python 3.10 of hoger.

BRONNEN EN TOEPASSING

Open-sourcesoftware.

NefisReader is een onafhankelijk project. Het is geen officieel product van Deltares en wordt niet door Deltares onderschreven.

Deltares ontwikkelt de NEFIS-bibliotheek. De broncode, kennisgevingen en bouwinstructies worden apart in de repository verspreid. De voorbeelden zijn synthetisch en bevatten geen scriptiegegevens.

De eigen code valt onder de MIT-licentie. Voor de NEFIS-bibliotheek van Deltares gelden de eigen kennisgevingen en licentie.
